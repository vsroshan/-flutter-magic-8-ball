Magic 8 Ball 🔮

A fun, interactive fortune-telling application built with Flutter and Dart.

The application generates randomized answers in response to user interaction, providing hands-on experience with state management and dynamic user interfaces.

📱 Overview

Magic 8 Ball recreates the experience of asking a question and receiving a randomized answer.

Users interact with the application to generate different responses, making it a simple demonstration of Flutter’s interactive capabilities.

✨ Features

* Interactive question-and-answer experience
* Randomized responses
* Dynamic image updates
* Tap-based interaction
* Simple and engaging interface

🛠️ Tech Stack

* Framework: Flutter
* Language: Dart
* Concepts: Stateful widgets, randomization, and event handling

📚 Key Learnings

* Managing changing UI state
* Generating randomized outcomes
* Handling user gestures
* Updating displayed content dynamically
* Organizing application logic and UI components

🚀 Getting Started

Prerequisites

Install Flutter and Dart and configure an emulator or physical device.

Installation

1. Clone the repository:

git clone https://github.com/vsroshan/flutter-magic-8-ball.git

2. Navigate into the project directory:

cd flutter-magic-8-ball

3. Install dependencies:

flutter pub get

4. Run the application:

flutter run
